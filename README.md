❤️ Cardiovascular Risk Prediction System

A Flask-based Machine Learning web application that predicts a person’s 10-year risk of heart disease using clinical and lifestyle data from the Framingham Heart Study.

🔗 Live Demo:
👉 https://cardiovascular-risk-prediction-0byp.onrender.com

📌 Project Overview

Heart disease is one of the leading causes of mortality worldwide.
This project provides a preventive risk assessment tool that helps users understand their long-term cardiovascular risk and take early lifestyle actions.

⚠️ Disclaimer:
This application provides a statistical risk estimate only and is not a medical diagnosis.

🧠 Key Features

🫀 Predicts 10-year heart disease risk

📊 Displays risk probability (%)

🟢 Categorizes risk into Low / Medium / High

🚀 How It Works

User enters lifestyle and health details

Input data is processed using the same ML pipeline used during training

Logistic Regression model predicts risk probability

Result is mapped to Low / Medium / High risk

User receives personalized health guidance

🧠 Key Learnings

Correct dataset selection is critical for ML success

Pipelines prevent data leakage

Probability-based predictions require domain thresholds

Frontend–backend alignment is essential in Flask

Ethical responsibility is crucial in healthcare ML
